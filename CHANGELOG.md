# Changelog

Last updated: November 2026 (v 1.4.0)

Future updates may include more characters, quality upgrades, and user-requested features.

## 1.4.0 | Stability Overhaul

- More accurate statistics — duplicate legacy sessions no longer count towards totals
- Reduced server load with better caching of character data and site-wide statistics
- Lighter recording of game results, keeping gameplay responsive
- More reliable database connections and hosting
- Updated core dependencies and removed unused components

## 1.3.0 | Archive & Personal Stats

- Added Archive Mode — play past your Dailies by solving previous days' challenges
- Added personal Stats modal with gameplay history and performance statistics
- Added easy navigation between archived challenges
- Fixed minor UI inconsistencies and visual bugs
- Numerous stability, accessibility, and quality-of-life improvements
