# Project

QSMPDLE is a daily guessing game based on QSMP Season 2 characters.

Main game modes:

- Daily
- Practice
- Archive

Primary technologies:

- .NET 10
- Blazor Web App
- MudBlazor
- ApexCharts
- EF Core
- SQLite

The application is intentionally built as a single-project solution.

Statistics are collected automatically from gameplay events.

Game state is stored in LocalStorage.

Long-term statistics are stored in SQLite.

The project values simplicity over abstraction.
