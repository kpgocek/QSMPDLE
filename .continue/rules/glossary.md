# Glossary

Character
A QSMP Season 2 character.

Member
The real content creator represented by a character.

Guess
One player attempt.

Game
A single play session.

Daily Game
The official game for a specific day.

Practice Game
A random game that does not affect daily progression.

Archive
Replay of a historical Daily Game.

PlayerStats
Browser-side progress.

GameSession
Persisted completed game used for statistics.

Retention
Percentage of players returning after N days.

Guess Distribution
Number of wins in 1..6 guesses.

Streak
Consecutive successful Daily Games.
